# Project Screenshots Guide

These screenshots are displayed inside your GitHub Profile README.

To customize them with actual browser captures of your apps:

### 1. `vaultmind-preview.png` (or `.svg`)
- **Recommended resolution:** `1280x720` (16:9 ratio) or `1200x675`
- **What to capture:**
  - Launch your Streamlit app: `streamlit run app.py`
  - Ask a question that produces an exact citation from your Obsidian notes (e.g. `[[raft#consensus]]`)
  - Show the dark-themed UI with the retrieved chunks and the Gemini Flash response
  - Save as `assets/screenshots/vaultmind-preview.png`

### 2. `signbridge-preview.png` (or `.svg`)
- **Recommended resolution:** `1280x720` (16:9 ratio)
- **What to capture:**
  - Open `https://sign-bridge-ai-alpha.vercel.app/`
  - Show the live camera feed with MediaPipe landmarks active on your hands
  - Show the predicted ISL sign label (or the two-way conversation / practice mode)
  - Save as `assets/screenshots/signbridge-preview.png`

> **Note:** High-fidelity vector preview SVGs (`vaultmind-preview.svg` and `signbridge-preview.svg`) are already provided and linked as defaults, so your profile README looks complete immediately without broken image links!
